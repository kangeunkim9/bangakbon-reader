# 방각본 고전소설 판독기

방각본 한글 고소설의 면 사진이나 PDF를 넣으면, 판본의 세로 행을 자동으로 나누고 행마다 글자를 읽어 텍스트로 옮기는 판독기입니다. 판독은 브라우저 안에서만 이루어지고, 올린 자료는 어디에도 보내지 않습니다.

> **시험판입니다.** 판독 모델은 아직 자료를 더 넣어 학습하는 중이라 오류가 적지 않습니다. 판독문은 검토용 초벌로만 쓰고, 인용할 때는 반드시 원문과 대조해 주세요. 모델이 나아지면 같은 주소에서 바로 바뀝니다.

**바로 쓰기: https://kangeunkim9.github.io/bangakbon-reader/**

만든 곳: 성균관대학교 국어국문학과 고전소설 연구실 김강은·이신영

이 저장소의 공개판에는 언어 모델 보정과 '학습용으로 보내기'가 빠져 있습니다. 둘 다 연구팀용 판독기에서만 씁니다(아래 '자료와 권리').

## 목표

이 판독기가 끝내 하려는 일은 **방각본을 판독한 뒤 문맥을 따져 띄어쓰기까지 넣은 전사문을 자동으로 만드는 것**입니다. 세 단계로 나아갑니다.

1. **판독** (지금 단계): 면 사진을 판본 행 그대로, 원문 표기대로 읽습니다. 글자 오류율 1% 미만이 목표입니다.
2. **띄어쓰기한 전사문**: 판독문에 문맥에 맞는 띄어쓰기를 자동으로 넣어, 바로 읽고 인용할 수 있는 전사문을 만듭니다. 원문 표기는 그대로 두고 띄어쓰기만 더합니다.
3. **넓히기**: 경판에서 완판과 다른 목판본으로, 나아가 필사본으로 넓힙니다.

판독이 정확해야 띄어쓰기도 제대로 할 수 있으므로, 지금은 판독 정확도를 올리는 데 힘을 쏟고 있습니다. 판독기에서 검수한 면을 '학습용으로 보내기'로 보내 주시면 다음 모델 학습에 씁니다. 판독기가 잘 안 되는 문제는 판독기 맨 아래 '문제 알리기'나 [이슈](https://github.com/kangeunkim9/bangakbon-reader/issues/new?template=problem.yml)로 알려 주세요.

|---|---|---|

| 6차 (모델만 키움) | 같음 | 7.0%, 보정 시 6.0% |
| 7차 | 경판 + AI허브 옛한글 목판본 VS_1 | 5.9% (AI허브 완판 소설 시험 3.6%, 5차 10.4%) |
| 8차 (웹 판독기에 들어 있음) | 7차 자료 + AI허브 TS_1, 모두 약 14만 행 | 5.85% (AI허브 완판 소설 시험 2.8%) |

- 금향졍긔는 학습에 쓰지 않은 작품입니다. 정답은 KOHICO 전사를 자동으로 맞춘 것이라 실제 오류율은 조금 낮습니다(검수 100행 기준 약 83% 수준).
- 판독문은 한 줄이 판본 한 행이고 오른쪽 행부터 놓입니다.

```

  index.html         빌드된 페이지 (엔진과 예시 면 판독 결과 포함)

  src/               페이지 원본, 판독 엔진(engine.js), 옛한글 자판(ime.js), 빌드 스크립트
  tests/             Python 판독기와 결과가 같은지, 공개판이 제대로 도는지 확인하는 시험
```

학습 스크립트와 노트북은 KOHICO 전사를 품고 있어 이 저장소에 넣지 않았습니다.

## 판독 방식

1. 면 사진을 이진화하고 테두리선을 지운 뒤, 열 방향 먹 분포로 행 간격과 경계를 찾아 세로 행을 자릅니다.
2. 행을 눕혀 높이 64픽셀로 맞추고 CRNN(합성곱 6층 + 양방향 LSTM 2층, CTC 학습)으로 자모 단위로 읽습니다.
3. (연구팀용 판독기) 언어 모델 보정을 켜면 KOHICO 경판 전사로 만든 자모 n-gram을 섞은 빔 탐색으로 애매한 글자를 고릅니다.

웹 엔진(`web/src/engine.js`)은 Colab 판독기의 Python 코드를 그대로 옮긴 것이고, 같은 면에서 행 경계와 판독문 15행이 모두 같게 나오는 것을 확인했습니다.

## 옛한글 입력

판독문을 고칠 때 한/영 상태와 상관없이 두벌식 자리 그대로 칩니다. ㅏ 두 번 → ᆞ, ᆞ 다음 ㅏ → ᆢ, Shift+ㅁ → ㅿ, Shift+ㅇ → ㆁ, Shift+ㅎ → ㆆ, 모음 없이 ㅂ+ㅇ → ㅸ, ㅅ+ㄱ → ㅺ 등. 읽을 수 없는 글자는 ` 키로 □를 넣습니다.

## 모델 바꾸기

1. Colab에서 새 모델을 ONNX(fp32, opset 17, 너비 축 가변)로 내보냅니다. 웹 실행기가 ConvInteger를 지원하지 않아 int8 양자화 모델은 쓸 수 없습니다.
2. 15MB 이하 조각으로 나눠 `web/model_v*_*.wasm` 자리에 두고, `web/src/page.src.html`의 `CFG.model`과 버전 표시를 고칩니다.
3. 예시 면 판독 결과(`web/src/sample_out.json`)를 새 모델로 다시 만들고, `python3 web/src/build.py`로 `index.html`을 다시 만듭니다.
4. main에 올리면 GitHub Pages에 자동으로 반영됩니다. 주소는 바뀌지 않습니다.
